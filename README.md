# Intelligent Voice-Assisted Healthcare Prescription System

A voice-assisted web application for real-time health consultations and prescription generation.

## Features
- Voice input for patient symptom collection
- Real-time doctor prescription generation
- Patient and doctor dashboard
- Secure MySQL database integration

## Tech Stack
- **Frontend:** HTML5, CSS3, Tailwind CSS
- **Backend:** Python Flask
- **Database:** MySQL
